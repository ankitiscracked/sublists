Troubleshooting
Updates: run the installer again, reload Sublists in Chrome's Extensions page, then refresh Substack.
If Notes permission was denied, enable Notes under System Settings → Privacy & Security → Automation. No Accessibility or Full Disk Access required.
Notes live under Substack in your default Notes account. To reload the library manually, use the refresh icon in Lists. Images download after saving; posts without an available thumbnail remain text-only.
